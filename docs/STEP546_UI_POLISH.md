# Step 546 — Primary-action label polish

Step 546 is a presentation-only refinement to the accepted Step 545 interface.

## Change

- Gold-filled primary actions now use the dedicated warm-charcoal label token
  `--primary-action-ink: #28251f` instead of the near-black `--gold-ink` token.
- The new color is slightly lighter and visibly greyer while retaining at least
  4.56:1 contrast against every normal and hover gold-gradient stop.
- Skip links, text selection, control hierarchy, hover treatment, focus rings,
  disabled states, layout, behavior, routes, and confirmations are unchanged.

## Non-effects

This milestone does not modify Registry, Pack, route, thread-binding, workspace,
Release, Discord, publishing, migration, archive, or persistence behavior.
