WHAT A PACK DOES

NOT ASSET METADATA

A Pack is an ordered publication batch. It defines capture scope, completeness, review order, Release history, the configured forum route, and persistent Pack/Asset thread ownership. Registry remains the source of Asset identity.

ORDERED BATCHDefines which Registry Assets belong together and their workflow order.
READINESS GATEAll required members must be captured, accepted, staged, and valid before publication.
RELEASE BOUNDARYArchive custody, interrupted Release recovery, and publication history are recorded per Pack.
FORUM ROUTEThe Pack logical channel resolves the Discord forum; each Pack/Asset pair owns one persistent thread binding.
